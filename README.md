# Tunnelwright Panel AWG

Панель управления VPN на [AmneziaWG](https://github.com/amnezia-vpn/amneziawg-go)
([wg-easy](https://github.com/wg-easy/wg-easy) 15.5) для нескольких серверов сразу: у пользователя
может быть несколько устройств, и каждое получает профиль с тем же IP на каждой ноде. Панель ставит
ноды сама, по SSH, держит их агентов в актуальной версии и собирает их данные в зашифрованные бэкапы.

## Возможности

### Пользователи и устройства
- Пользователь — человек: имя, группа, заметка, срок доступа, квота трафика и личная ссылка.
  Включение, отключение и срок действуют сразу на все его устройства.
- Устройство (конфиг) создаётся под пользователем: своё название, IP из подсети (по умолчанию —
  первый свободный) и ключи; профиль с тем же IP — на каждой ноде, на нодах подписан
  «Пользователь · устройство».
- Конфиг `.conf` и QR-код каждого устройства для каждой ноды; отправка в Telegram.
- Включение и отключение отдельного устройства, смена его названия и IP; автоотключение
  пользователя по истечении срока.
- Лимиты скорости (скачивание и отдача, Мбит/с) — на устройство, на всех нодах, следуют за его IP.
- Квоты трафика на календарный месяц — на пользователя (все устройства): предупреждение на 80 %,
  отключение на 100 %, включение обратно в новом месяце.
- Объединение пользователей: устройства переходят к одному пользователю без смены ключей.
- Группы с цветом и порядком, фильтр по группе, поиск по имени, устройству, IP, заметке и скрытому ID.
- Скрытый постоянный ID: одинаковые имена разрешены, профили на нодах привязаны к устройству по ID.

### Ноды
- Добавление сервера по SSH (пароль root или ключ используются один раз): установка Docker,
  wg-easy и агента, ключ SSH-хоста запоминается и сверяется, ход установки виден в панели.
- Агент ноды: HTTPS с закреплённым сертификатом и токен ноды; по умолчанию принимает запросы
  только с IP панели.
- Автообновление агентов до версии панели — без SSH; при недоступном образе агент собирается на ноде.
- Обновление и переустановка по SSH, в том числе на переустановленный сервер — с прежними ключами
  из бэкапа, клиентам не нужно менять конфиги.
- Удаление «только из панели» или «с сервера» (контейнеры, данные, образы, правило ufw).
- Состояние и нагрузка: CPU, RAM, диск, трафик, версия агента, сертификат.
- Блокировка торрент-трафика по сигнатурам протокола (рукопожатие пиров, трекеры, DHT) —
  без блокировки портов и ограничения числа соединений.
- VPN на сервере самой панели — по желанию (`tunnelwright local-vpn on|off`).

### Статистика и журнал
- Обзор: пользователи онлайн, трафик в реальном времени, графики за час, сутки, неделю и 30 дней,
  топ пользователей по трафику за месяц, полгода и год, нагрузка серверов.
- Учёт трафика на сервере с границами суток по часовому поясу панели.
- Журнал действий: входы, изменения пользователей и устройств, нод, настроек и бэкапов.

### Доступ и безопасность
- Вход по логину и паролю, двухфакторная аутентификация (TOTP), блокировка после неудачных попыток.
- HTTPS с самоподписанным сертификатом и автоматическим продлением; наружу открыты только порт
  панели и UDP-порт VPN.
- Токен Telegram-бота и ключи устройств не попадают в браузер.

### Telegram
- Уведомления по выбранным событиям: запуск панели, новое устройство (с конфигом и QR), удаление,
  включение и отключение, лимиты, недоступность и восстановление нод.
- Бот для администратора: `/status`, `/clients`, `/client`, `/conf`, `/add`, `/device`, `/enable`, `/disable`,
  `/link`, `/backup`.

### Страница пользователя
- Личная ссылка пользователя без входа в панель: статус, срок, трафик и квота, QR и конфиги всех его устройств.
- Ссылки можно давать на отдельном домене (например, основном при панели на поддомене) — там
  открываются только страницы пользователей.
- Шаблон страницы с упрощённой разметкой, подстановками и предпросмотром; ссылку можно
  создать, заменить или отозвать.

### Маршрутизация WireSock
- Справочник списков: страны (GeoIP), подсети, приложения и папки.
- Для устройства — AllowedIPs, исключения, приложения через VPN или мимо него; итоговый конфиг
  выдают QR, файл, страница пользователя и бот.

### Бэкапы
- Зашифрованный архив (AES-256 ZIP): данные панели и ключи всех нод.
- По расписанию (ежедневно или еженедельно) с отправкой в Telegram; последние 5 копий на сервере.
- Восстановление командой `tunnelwright restore` или в интерфейсе (на NAS).

### Интерфейс
- Боковое меню, тёмная и светлая темы, мобильная вёрстка.
- Название панели, часовой пояс и шаблоны настраиваются в интерфейсе.

## Установка на сервер

Debian или Ubuntu, root:

```bash
curl -fsSL https://raw.githubusercontent.com/prg77/tunnelwright-panel-awg/main/install.sh | bash
```

Загрузчик скачает последний релиз, проверит sha256 и запустит установщик. Параметры без вопросов —
через `install.env` (см. [install.env.example](install.env.example)) рядом с `install.sh`.

| Флаг | Что делает |
|---|---|
| `--version v1.0.1` | установить конкретный релиз |
| `--channel dev` | установить ветку без релиза (версия `dev-<коммит>`, образы собираются на сервере) |
| `--build-local` | собрать образы на сервере вместо GHCR |
| `--reuse` | переустановка с сохранёнными параметрами, без вопросов |

Панель открывается по **HTTPS** с самоподписанным сертификатом (браузер покажет предупреждение;
отпечаток для проверки выводит установщик). Вход — `admin` и пароль, заданный при установке.

Установка amnezia-wg в `/opt/amnezia-wg` переносится автоматически: клиенты сохраняют ключи
и конфиги, при ошибке установщик возвращает прежнюю установку.

## Установка на NAS (Portainer)

Только панель, VPN — на удалённых нодах: стек [deploy/portainer/docker-compose.yml](deploy/portainer/docker-compose.yml),
инструкция — [docs/portainer.md](docs/portainer.md). Процессор amd64 или arm64.

## Управление

```bash
tunnelwright status | logs [сервис] | restart
tunnelwright update [vX]     # обновиться до последнего релиза или vX
tunnelwright rollback        # вернуть предыдущий релиз
tunnelwright backup          # бэкап сейчас
tunnelwright restore файл    # восстановить из бэкапа
tunnelwright reset-admin     # новый пароль администратора, 2FA выключается
tunnelwright cert            # перевыпустить TLS-сертификат
tunnelwright local-vpn on|off  # VPN на сервере панели
```

Код релизов — `/opt/tunnelwright/releases/<версия>`, активный — симлинк `/opt/tunnelwright/current`.
Данные — docker-тома `tunnelwright_wg` (ключи VPN), `tunnelwright_data` (панель и бэкапы), `tunnelwright_node` (агент).

## Структура

```
install.sh              загрузчик релизов из GitHub
installer/              установщик: модули, шаблон docker-compose.yml
deploy/portainer/       стек для Portainer (NAS)
web/                    React UI + nginx (HTTPS), образ ghcr.io/prg77/tunnelwright-web
panel/                  panel-api (FastAPI + SQLite), образ ghcr.io/prg77/tunnelwright-api
node/                   node-agent (wg-easy API, tc-лимиты, метрики), образ ghcr.io/prg77/tunnelwright-node
host/                   команды хоста: tunnelwright, продление сертификата, watchdog
docs/                   архитектура, Portainer
branding/               логотип: SVG, PNG, favicon
```

Архитектура — [docs/architecture.md](docs/architecture.md).

## Разработка

Тесты panel-api — `cd panel && python -m pytest`, фронтенд — `cd web && npm ci && npm run lint && npm run build`.
CI гоняет то же на каждый push.

## Релиз

1. Обновить `VERSION` и версию в `web/package.json`.
2. `git tag v$(cat VERSION) && git push origin main --tags`.
3. GitHub Actions соберёт архив и `SHA256SUMS`, опубликует три образа в GHCR (amd64 и arm64)
   и создаст релиз с описанием из [.github/release-notes.md](.github/release-notes.md).
